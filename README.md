【游戏名称】
太空滑板 - 重构版

【游戏介绍】
这是一款使用Three.js 3D引擎开发的太空主题滑板竞速小游戏。游戏中，你驾驶着未来科技滑板在太空轨道上高速滑行，需要灵活躲避前方不断出现的障碍物。本版本采用太空科幻视觉风格，深邃星空背景，炫酷的滑板特效。

【玩法说明】
游戏中，你的滑板会自动向前滑行，障碍物会从前方不断出现。

障碍：
1. 障碍物会从前方随机出现，速度会随着得分增加而加快。
2. 撞到障碍物游戏结束。
3. 滑行距离越远，得分越高。

操作：
点击或触摸屏幕左侧 - 向左移动滑板。
点击或触摸屏幕右侧 - 向右移动滑板。
键盘左右方向键 - 控制滑板左右移动。

目标：
躲避障碍物，滑行尽可能远的距离，获得更高的分数！

Tips：游戏结束会记录你的最高分数。
注意观察前方障碍物，提前做出反应！速度会越来越快！

【技术介绍】
使用Three.js 3D图形引擎开发（版本r128），主要语言是JavaScript，使用了WebGL渲染技术，3D物理引擎，碰撞检测系统，阴影系统等。
